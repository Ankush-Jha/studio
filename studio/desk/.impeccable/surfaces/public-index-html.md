# Surface: Desk (all screens)

Mode: operate. Audience: agency owner; sees state at a glance, decides at two gates. Unattended subagent build; direction inferred from the brief, which pins the world ("think film production board + broadcast control room", "dark theme first (control room) with a proper light theme too").

## Direction contract

THESIS: The Desk is a production board for a content studio: every job is a strip moving through stations, images lead, and status is read like tally lights. It refuses the admin template (KPI tiles, card grids of icon+text, grey with one accent).

OWN-WORLD: Graphite control-room ground (cool near-black, never pure), a committed dark slate rail, tally state colours (green running, amber waiting, red failed), one reserved course violet for the selected job's route, and Kodak-amber edge print. Archivo across UI and condensed display (wdth axis); Martian Mono condensed for edge print, timecode and metrics. Hairline rules, square corners (2px max), dense 4px rhythm.

STORY: Open the Desk, see the whole system flowing, spot the amber gate, click into the job, pick a concept or approve the cut, watch the graph advance.

FIRST VIEWPORT: Left rail (nav with live counts). Main: Flow canvas, system graph left-to-right as stations with bezier edges and travelling frames; amber-glowing gates. Bottom of canvas: active-job strip (stripboard). Right: drawer on node click. Footer: edge-print activity ticker.

FORM: grounded candidate 5 (film edge print) inside the brief-pinned world; seed:394f14daca72f585. Signature move: edge print, a mono amber metadata band along every media object and the screen's bottom edge, plus frames travelling along double-hairline edges. Raises: from orienteering-map, one reserved course colour for the active job route; from crouwel-grid-specimen, walls reflow in whole cells.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
